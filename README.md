# السفر عبر المكان 🌍

**لا تقرأ التاريخ... ادخل إليه.**

موسوعة زمنية تفاعلية لكل مكان — نبدأ بالإنسان لنكتشف تاريخ المنطقة.

## الفلسفة
- نبدأ من: عائلة → بيت → زقاق → قرية → منطقة → تاريخ أوسع (وليس العكس).
- كل معلومة تحمل هويتها: 🟢 موثقة بوثيقة | 🔵 مدعومة بصورة | 🟡 رواية شفوية | 🟠 استنتاج من مصادر | 🔴 إعادة بناء بالذكاء الاصطناعي.
- مجاني للجميع — الربح من خدمات المؤسسات (بلديات، متاحف، جامعات، سياحة) وليس من الذاكرة.

## الرحلة الأولى (تجريبية)
الجيزة — ريف درعا — سنة 1950: المكان، العائلة، العملة، التجارة، الحروب والأحداث، العادات، مقارنة 1950 × 2026.

## التشغيل
- الموقع: نشر تلقائي من فرع `main` عبر Vercel.
- المرحلة 1: الصفحة الرئيسية (تمت).
- المرحلة 2: صفحة المكان + السفر عبر الزمن + قاعدة البيانات.
